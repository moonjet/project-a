## 📋 BULK PRICING CHECK
Copy and paste this query, replace [TOOLS] with your list:

"""
Check the current pricing for these AI tools as of January 2026:
- Perplexity
- ChatGPT
- Claude
- Cursor
- GitHub Copilot

For each tool, provide:
1. All pricing tiers (name and monthly price)
2. Key features for each tier
3. Any recent pricing changes

Format as a table for easy copy/paste into spreadsheet.
"""

## 🆕 NEW FEATURES CHECK
For individual tools:

"""
What new features and updates did [TOOL NAME] release in the last 3 months?
Include:
- Version numbers and release dates
- Major new features
- Pricing changes
- New integrations
"""

## ⭐ RATINGS UPDATE
Bulk ratings check:

"""
What are the current ratings (out of 5) for these AI tools:
- [Tool 1]

- [Tool 3]

Check G2, Product Hunt, Trustpilot, and Capterra.
Provide average rating and review count.
"""

## 🚀 NEW TOOL DISCOVERY
Find emerging tools:

"""
What are the top 5 new AI [CATEGORY] tools launched in the last 3 months?
For each, provide:
- Name and website
- Brief description
- Pricing
- Key differentiator
- User ratings if available
"""

## 🔄 BATCH UPDATE WORKFLOW

### Weekly Quick Check (5 minutes):
Ask Perplexity: "Any major pricing or feature updates for Perplexity, ChatGPT, Claude, Cursor, Windsurf this week?"

### Monthly Deep Dive (30 minutes):
1. Run bulk pricing check
2. Check new features for top 10 tools
3. Update ratings
4. Discover 3-5 new tools to add

### Quarterly Audit (2 hours):
1. Verify all tool URLs still work
2. Check if any tools shut down
3. Update all descriptions
4. Refresh all version timelines
