🔧 HOW TO UPDATE BADGES IN JSON
─────────────────────────────────────────────────────────────────

1. Each tool has TWO badge fields:
   {
     "cornerBadge": "BEST",              // ← What displays
     "allBadges": ["POPULAR", "BEST"]    // ← All possible badges
   }

2. To change a badge, edit "allBadges" array:
   {
     "name": "ChatGPT",
     "allBadges": ["POPULAR", "BEST", "OFFER"]  // ← Add OFFER
   }

   System will automatically show "OFFER" (priority 10)

3. To add promotional badge:
   {
     "name": "DeepSeek",
     "allBadges": ["VALUE", "NEW", "DISCOUNT"]  // ← Add DISCOUNT
   }

   System will show "DISCOUNT" (priority 9 > 8 > 5)

4. To remove badge completely:
   {
     "allBadges": []  // ← Empty array = no badge
   }

🎯 BEST PRACTICES
─────────────────────────────────────────────────────────────────

✓ DO:
  • Use OFFER/DISCOUNT sparingly (limited time only)
  • Give NEW badge to tools added in last 30 days
  • Use VALUE for genuinely good pricing
  • Update UPDATED badge after major releases

✗ DON'T:
  • Give every tool a badge (dilutes impact)
  • Keep OFFER badges after promotion ends
  • Overuse BEST (only top 3-5 tools)
  • Mix similar badges (e.g., NEW + UPDATED)

Good Examples:
  ✓ ["POPULAR", "BEST"] - Makes sense
  ✓ ["FAST", "VALUE"] - Complementary
  ✓ ["NEW", "OFFER"] - Promotional launch

Bad Examples:
  ✗ ["NEW", "UPDATED"] - Redundant
  ✗ ["BEST", "TOP"] - Too similar
  ✗ ["OFFER", "DISCOUNT"] - Pick one
